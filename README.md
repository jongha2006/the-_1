# the 해커톤_1

두 명이 함께 만드는 해커톤 프로젝트입니다.

## 시작하기

1. 저장소 소유자 `jongha2006`가 Settings → Collaborators에서 `kkukku06`을 초대합니다.
2. 동기는 GitHub 초대를 수락합니다.
3. 각자 컴퓨터에서 저장소를 복제합니다.

```sh
git clone https://github.com/jongha2006/the-_1.git
cd the-_1
```

개발 언어, 실행 방법, 프로젝트 소개는 기술 스택을 정한 뒤 이 문서에 추가합니다.

## 함께 작업하는 순서

1. Issues에서 작업을 등록하고 담당자를 한 명 정합니다.
2. 작업 전 최신 main을 받고 자기 브랜치를 만듭니다.
3. 작업 후 push하고 GitHub에서 main으로 Pull Request(PR)를 엽니다.
4. 상대가 변경 내용을 확인한 뒤 Squash and merge로 합칩니다.
5. 다음 작업 전 main을 다시 갱신합니다.

자세한 명령어와 충돌 해결 방법은 [협업 안내](CONTRIBUTING.md)를 참고하세요.

## 먼저 정할 것

- [ ] 만들 서비스와 핵심 기능 3개
- [ ] 개발 언어와 프레임워크
- [ ] 각자 담당할 기능
- [ ] 실행 및 배포 방법

## 기본 약속

- main은 함께 실행할 수 있는 버전으로 유지합니다.
- 브랜치는 `feat/기능명`, `fix/문제명`처럼 작업별로 만듭니다.
- 같은 파일을 동시에 크게 수정하기 전 서로 알려줍니다.
- 비밀번호, API 키, 실제 .env 파일은 올리지 않습니다.
